## 🚀 Quick Run Commands

```bash
# 1. Install dependencies
flutter pub get

# 2. Run in Web Browser
flutter run -d chrome

# 3. Run on connected Android device
flutter run -d android
```

## 🌟 Modules & Features
* **Adaptive Multi-Platform Shell**: Linear/Raycast inspired desktop sidebar (`>= 1024px`) and thumb-friendly mobile bottom navigation (`< 1024px`).
* **Geofencing State Engine**: Continuous GPS stream evaluation, noise filtering, and discrete state machine triggers.
* **Native Sound Mode Profiles**: Silent, Vibrate, and Normal mode switches with automatic exit restoration.
* **Location Alarm Loop**: Sustained audio and vibration alerts with dismiss overlay banner.
* **OpenStreetMap Radar**: Dynamic radius visualizer and address autocomplete.
* **SQLite Persistence**: Offline-first rule caching and trigger history.
